## Was ist GitHub eigentlich?

Kurz gesagt: **GitHub ist eine cloudbasierte Plattform zur Versionsverwaltung und Zusammenarbeit an Code** (basierend auf dem System *Git*). Stellt es euch wie ein gemeinsames, extrem strukturiertes digitales Notizbuch für Softwareprojekte vor:

* **Versionsverlauf:** Jede Änderung am Code wird nachvollziehbar gespeichert – ihr könnt jederzeit sehen, wer was wann geändert hat, und bei Bedarf zu älteren Ständen zurückkehren.
* **Zusammenarbeit:** Mehrere Personen können gleichzeitig an Projekten arbeiten, Änderungen vorschlagen und Code gemeinsam weiterentwickeln, ohne sich gegenseitig Dateien zu überschreiben.
* **Zentrale Anlaufstelle:** Für diesen Kurs dient GitHub als unser „Single Point of Truth“ für alle technischen Materialien.

## Unser KI-Manifest: Sparringspartner statt Ghostwriter

KI-Tools sind aus der modernen Softwareentwicklung und Datenanalyse nicht mehr wegzudenken – und in diesem Kurs ausdrücklich erlaubt. Entscheidend ist aber **wie** ihr sie nutzt. Es gilt eine einfache Grundregel: **Nutzt KI, um schlauer zu werden – nicht, um den Weg abzukürzen.**

### ✅ So macht euch euer Chatbot besser

Setzt KI als Tutor, Code-Reviewer und Ideengeber ein, nachdem ihr selbst gedacht habt. Gute Prompts erkennt ihr daran, dass sie euer Verständnis vertiefen:

* *„Wie könnte ich diesen Code eleganter oder performanter lösen?“*
* *„Ich habe diesen Ansatz gewählt – habe ich hier noch einen Edge-Case übersehen?“*
* *„Welche alternativen Lösungswege gibt es für dieses Problem?“*
* *„Was genau sagt mir diese Fehlermeldung und warum tritt sie hier auf?“*
* *„Welche Konzepte sollte ich mir in diesem Kontext noch anschauen?“*

### ❌ So verhindert ein Chatbot Lernen

Wer die Denkarbeit komplett auslagert, betrügt sich selbst um genau die Fähigkeiten, für die ihr dieses Studium macht. Prompts, die euch nicht weiterbringen:

* *„Hier ist meine Aufgabenstellung, löse das für mich.“*
* *„Kannst du dieses Übungsblatt komplett für mich ausarbeiten?“*
