# Templates für Code Files

In diesem Ordner stelle ich euch Vorlagen für unsere Übungsblätter zur Verfügung. Ladet euch diese Vorlagen herunter, kopiert sie in euren Arbeits-Ordner und ändert den Namen - dann könnt ihr auch schon loslegen. Im oberen Teil der Vorlage findet ihr immer die Megatutorial-Aufgaben, an denen wir gemeinsam arbeiten. Im unteren Teil der Übungsblätter findet ihr die Individualaufgaben, an denen ihr selbst arbeitet.

Happy Coding 🚀.
